# 📖 Работа с файлами и кулинарная книга (Python)

Учебный проект по курсу «Основы Python», посвящённый чтению, обработке, сортировке и записи текстовых файлов (`open`, `read`, `write`, кодировка `UTF-8`), а также работе со словарями и списками.

---

## 🛠 Реализованный функционал

В проекте решены три последовательные задачи:

1. **Чтение кулинарной книги (`read_cook_book`)**
    * Считывает рецепты из текстового файла `recipe.txt`.
    * Преобразует данные в структурированный словарь `cook_book`, где ключ — название блюда, а значение — список словарей с ингредиентами, их количеством и единицами измерения.

2. **Расчёт списка покупок (`get_shop_list_by_dishes`)**
    * Принимает список выбранных блюд, количество персон и словарь `cook_book`.
    * Вычисляет необходимое количество каждого ингредиента и автоматически суммирует повторяющиеся продукты из разных блюд.

3. **Сортировка и объединение файлов (`merge_files`)**
    * Считывает несколько текстовых файлов (`1.txt`, `2.txt`, `3.txt`), подсчитывает количество строк в каждом из них.
    * Сортирует файлы по возрастанию количества строк и объединяет их содержимое в итоговый файл `result.txt` с добавлением служебной информации (имя исходного файла и число строк).

---

## 📂 Структура проекта

* `recipe.py` — основной скрипт с реализацией всех функций и тестовым запуском.
* `recipe.txt` — исходный файл с базой рецептов.
* `1.txt`, `2.txt`, `3.txt` — исходные текстовые файлы для задачи по объединению.
* `result.txt` — результирующий файл, генерируемый программой.

## 🚀 Как запустить проект

1. Клонируйте репозиторий на компьютер:
   ```bash
   git clone https://github.com
   ```
2. Перейдите в папку проекта:
   ```bash
   cd NetologiaRecepts
   ```
3. Убедитесь, что рядом со скриптом находятся файлы `recipe.txt`, `1.txt`, `2.txt`, `3.txt`, и запустите программу:
   ```bash
   python recipe.py
   ```
